# Skill: JRA 重要賽事查詢

## 觸發條件

當使用者詢問以下類型的問題時啟用此 skill：
- 「最近的賽馬比賽」「最近的賽事」「這週有什麼比賽」
- 「JRA」「G1」「G2」「G3」「重賞」等關鍵字
- 「賽程表」「比賽日程」「賽馬日程」

---

## 執行步驟

### Step 1：取得今日日期
先確認今天的日期，計算「今天」到「七天後」的範圍。

### Step 2：抓取 JRA 賽程資料

使用 WebFetch 取得以下頁面（選其一或依序嘗試）：

**本週賽程：**
```
https://www.jra.go.jp/keiba/thisweek/
```

**整體賽程（包含未來數個月）：**
```
https://www.jra.go.jp/keiba/schedule/
```

若上述頁面無法取得，嘗試：
```
https://www.jra.go.jp/datafile/seiseki/replay/
```

### Step 3：篩選重賞賽事（G1 / G2 / G3）

從頁面內容中找出包含以下關鍵字的賽事：
- `GⅠ` / `G1` / `GI`
- `GⅡ` / `G2` / `GII`
- `GⅢ` / `G3` / `GIII`
- `重賞`

### Step 4：判斷回應方式

**情況 A：一週內有賽事**
列出未來七天內所有 G1～G3 賽事，格式如下：

```
📅 最近一週的 JRA 重賞賽事：

🏆 [日期] [賽事名稱]（[等級]）
　　賽場：[競馬場名稱]
　　距離：[距離]
　　（若有其他資訊可補充）
```

**情況 B：一週內無賽事**
告知最近一場即將舉行的 G1～G3 賽事：

```
最近一週沒有 JRA 的重賞賽事。
最近的一場是：
🏆 [日期] [賽事名稱]（[等級]）
　　賽場：[競馬場名稱]
```

---

## 回應風格

請維持大和赤驥的角色口吻回答，例如：

> 「哼，你想了解賽程嗎？就由人家幫你查一查吧……這是最近的重賞賽事喔！」

若查詢失敗（頁面無法存取）：
> 「……這次人家查不到。JRA 的網站可能有點狀況，之後再試試看。」

---

## 注意事項

- 只回報 **G1、G2、G3** 等級的重賞賽事，忽略一般賽事
- 日期格式統一使用 **YYYY年MM月DD日（星期X）**
- 若頁面為日文，直接解讀日文賽事名稱並輸出
