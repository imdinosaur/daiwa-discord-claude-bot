# Gamma 報告（台指選擇權造市商 gamma）

## 取得資料

```bash
node scripts/gamma_today.ts            # 最近一個交易日
node scripts/gamma_today.ts 2026-11-13 # 指定日
```

輸出是 JSON（stdout），價位都已換算成加權指數現貨點數；下載進度在 stderr。約需 10 秒，資料來自期交所 TXO 日資料與證交所加權指數。計算方法來自 `gamma-sentiment` 專案（`lib/gamma/`），不要自己重算或改數字。

## 欄位

| 欄位 | 意思 |
|---|---|
| `date` / `nextDay` | 資料日 / 燈號適用的下一個交易日 |
| `light`, `lightLabel`, `action` | 燈號（red 減碼 / yellow 警戒 / blue 上行較易 / green 對稱） |
| `regime.label` | 收盤處為正 gamma（波動被壓低）或負 gamma（波動被放大） |
| `close`, `priceSource` | 收盤價；`F0` 表示查無收盤、以遠期價代替（要註明） |
| `flip`, `flip_dist` | gamma 翻轉價位、與收盤的距離（以預期波動 h 為單位） |
| `callWall`, `putWall` | 買權牆（上方壓力）、賣權牆（下方支撐） |
| `box` | 收盤上下最近的價位，當作震盪空間 |
| `h`, `sigma` | 3 日曆日預期波動（點數）、價平隱含波動率 |
| `cone` | 1/3/5/7 日 ±1σ、±2σ 預期波動範圍 |
| `settlingExpiries` | 即將結算的到期日（結算後 gamma 緩衝可能消失） |

## 兩種模式

- **盤前模式**（開盤前）：若 `nextDay` 不是今天，代表今天不是交易日，**不發送**，只在終端機記錄。否則報告「今天」該注意什麼：燈號、正負 gamma、震盪空間、flip 距離、1 日波動範圍。
- **盤後模式**（收盤後）：若 `date` 不是今天，代表今天沒開盤或期交所資料還沒出來；前者不發送，後者在頻道說明「資料尚未公布」，不要拿前一天的資料冒充。否則報告今天的結果與明天的燈號。

## 發送格式

一則訊息，條列，不超過 1000 字，不用表情符號：

```
**台指 Gamma｜2026-11-13 盤後**
燈號：綠燈（對稱）｜收盤處為正 gamma，波動傾向被壓低
收盤 43,675｜flip 41,834（距離 1.32h）
震盪空間：42,833（賣權牆）～ 43,830（買權牆）
明日 ±1σ：42,873 ～ 44,477
（一句話重點：例如「收盤貼近買權牆，上方空間有限」）
本報告為選擇權結構分析，不構成投資建議。
```

- 數字照 JSON，不四捨五入成別的值、不推測 JSON 裡沒有的東西。
- 最後一行的免責聲明一定要有。
